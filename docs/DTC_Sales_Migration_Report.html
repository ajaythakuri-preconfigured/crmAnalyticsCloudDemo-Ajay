Executive Summary

Overview

This report documents the successful migration of the DTC Sales Dashboard from Salesforce CRM Analytics to Tableau Next (Tableau CRM / Data 360). The migration preserves all original KPI metrics — Total Pipeline, Open Pipeline, Won Revenue, and Lost Revenue — while upgrading the underlying data platform from proprietary CRM Analytics datasets to Salesforce Data Cloud, and the visualisation engine from SAQL to Tableau's VizQL. The migrated dashboard delivers the same business insights on a modern, scalable, AI-ready platform.

Technical Journey

How the Migration Was Done

Key steps taken to complete the migration from CRM Analytics to Tableau Next.

1

Audit CRM Analytics Dashboard

Retrieved all CRM Analytics metadata via SFDX CLI. Parsed dashboard JSON to extract widget types, field names, aggregations (Sum of Amount), and sort orders. Ran SOQL against the CRM Analytics org to document all field names.

✅ Automated by Halo
2

Set Up Data Cloud & Semantic Model

Confirmed the Data Lake Object (DLO) existed in Data Cloud. Created the Semantic Model in the Tableau Next UI, exposing Amount, Stage, Close Date, Owner Name, and other fields from the Opportunity DLO.

🖥️ UI Required — SM creation
3

Discover SM Field Names

Tableau Next assigns numbered suffixes to SM fields (e.g. Amount → Amount_mtc, Close_Date → Close_Date_mtc). Used a deploy-and-fail loop to discover exact field names by iterating through suffixes until deployment succeeded.

✅ Automated by Halo
4

Create Workspace & Visualizations

Created the Tableau Next workspace via SFDX metadata deploy. Generated four KPI viz XML files and one line chart viz — all with brand-new API names to ensure correct SM binding from first creation.

✅ Automated by Halo
5

Build & Deploy Dashboard

Generated the dashboard XML with 48-column grid layout, dark navy styling, filter widgets (year toggle), and viz widget references. Deployed vizes first, then the dashboard. Verified all components opened correctly.

✅ Automated by Halo
6

Commit to Git & Raise PR

All metadata files committed to the feature branch feature/tableau-next-dtc-sales-migration in GitHub. Pull request raised with full description of changes. Documentation committed alongside code.
